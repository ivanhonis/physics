# physics.ndot.io: published research

This repository mirrors the research published at https://physics.ndot.io. Each folder is one published subproject, exactly as the site shows it: the base problem, every package with its question, all versions of the derivation, the external reviews and the code.

It is written automatically whenever a subproject is published; changes made here by hand are overwritten.

## Subprojects

### [Space from a description language](03-ilang-space/)

Can a space-like structure (distance, dimension, locality, bodies, motion) be derived inside the description language Ilanguage 1.b from its own elements alone, without importing any spatial notion? The first stage of a research programme on gravity.

On the site: https://physics.ndot.io/03-ilang-space/

## Author

Ivan Honis, ivan.honis@ndot.io. The research is done by a human and AI together; the [Human–AI note](https://physics.ndot.io/human-ai-note) says who contributed what.
